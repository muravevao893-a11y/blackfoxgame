# BlackFox Game Bot

**BlackFox Game** — виртуальный игровой Telegram-бот в стиле экономической игры: баланс, бонусы, казино, кейсы, промокоды, магазин, бизнесы, банк, кланы и топы.

> В проекте нет реальных денег, ставок, криптовалюты или вывода средств. Только виртуальная валюта **Фоксы**.

## Быстрый запуск

```bash
npm install
cp .env.example .env
```

Заполни `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/blackfoxgame
ADMIN_IDS=твой_telegram_id
BOT_USERNAME=юзернейм_бота_без_@
```

Создай таблицы:

```bash
npm run db:init
```

Запусти бота:

```bash
npm start
```

## Создать промокод

```bash
npm run promo:create START 50000 25 1000
```

Формат:

```bash
npm run promo:create КОД ФОКСЫ КРИСТАЛЛЫ ЛИМИТ_АКТИВАЦИЙ
```

В боте:

```text
промо START
```

## Админ-команды в Telegram

Работают только для ID из `ADMIN_IDS`.

```text
/adm_give @username 100000
/adm_give_id 123456789 100000
/adm_promo START 50000 25 1000
/adm_stats
```


## Большой пак систем Burmaldance

Добавлены команды:

```text
шар фраза
выбери фраза или фраза2
инфа фраза
испытать удачу
```

Браки:

```text
свадьба ID_пользователя
мой брак
развод
```

Кейсы с инвентарём:

```text
кейсы
купить кейс 1 5
открыть кейс 1 5
```

Пассивный доход:

```text
бизнес / мой бизнес / построить бизнес
бизнес собрать
бизнес налоги
увеличить территорию
увеличить бизнес

ферма / моя ферма / построить ферму
собрать прибыль
оплатить налоги
купить видеокарту
улучшить ферму

генератор / мой генератор / построить генератор
карьер / мой карьер / построить карьер
денежное дерево / моё дерево / построить участок
сад / мой сад / построить сад
```

У бизнеса и майнинг-фермы есть inline-кнопки как в BFG-style интерфейсе: сбор прибыли, налоги, улучшения и покупка видеокарт.

Продажа пока специально выключена:

```text
продать бизнес
продать генератор
продать ферму
продать карьер
продать участок
продать сад
```

Сад и зелья:

```text
сад полить
зелья
создать зелье 1
создать зелье 2
создать зелье 3
```

Зелья дают бонусы к кейсам, пассивному доходу и команде `испытать удачу`.

## Обновление: BFG-like сад

Добавлена карточка сада как на скриншоте:

- `сад` / `мой сад` — показать карточку сада с кнопками
- `построить сад` — создать сад
- `сад собрать` / кнопка `💰 Собрать прибыль`
- `сад налоги` / кнопка `🦅 Оплатить налоги`
- `купить дерево` / кнопка `⬆️ Купить дерево`
- `сад полить` / кнопка `💦 Полить сад`

В карточке показывается доход, деревья, цена следующего уровня, вода, налоги и счёт сада.
