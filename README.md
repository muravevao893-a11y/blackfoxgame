# BlackFox Game — Mega Pack

Telegram-бот с игровой экономикой на виртуальной валюте: Фоксы и Кристаллы. Без реальных ставок, вывода денег и крипты.

## Запуск

```bash
npm install
cp .env.example .env
npm run db:init
npm start
```

В `.env`:

```env
BOT_TOKEN=токен_от_BotFather
DATABASE_URL=postgresql://...
ADMIN_IDS=твой_telegram_id
```

Для Railway нужна база PostgreSQL и переменная `DATABASE_URL=${{Postgres.DATABASE_URL}}`.

## Важно про 409 Conflict

Если Telegram пишет `409: Conflict`, значит этот же токен уже запущен где-то ещё или Railway поднял больше одной реплики. Нужно оставить только один активный процесс и сделать `deleteWebhook?drop_pending_updates=true`.

## Pro Group Pack

В этой версии добавлена нормальная работа в группах:

- приветствие при добавлении бота в группу;
- отдельное меню команд для ЛС и групп;
- slash-команды для групп: `/help`, `/profile`, `/balance`, `/casino 1000`, `/casino all`, `/top`, `/chat_top`;
- красивые HTML-карточки профиля, баланса и меню;
- кнопки меню для ЛС и групп;
- автоматическая регистрация команд в Telegram через `setMyCommands`;
- запуск с `dropPendingUpdates: true`, чтобы меньше ловить старые апдейты после деплоя.

### Почему бот не реагирует в группах на обычные слова

Telegram по умолчанию включает Privacy Mode. С ним бот видит в группе только:

- сообщения-команды через `/`, например `/help`;
- ответы на сообщения бота;
- упоминания бота;
- сервисные события типа добавления в чат.

Чтобы команды без слэша вроде `баланс`, `казино 1000`, `сад` работали прямо в группе, отключи Privacy Mode:

1. Открой `@BotFather`.
2. `/mybots`.
3. Выбери своего бота.
4. `Bot Settings`.
5. `Group Privacy`.
6. `Turn off`.
7. Удали бота из группы и добавь заново.

Даже с включенным Privacy Mode slash-команды в группах уже работают.
